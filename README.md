# codingame-challenges

A collection of my solutions and experiments on [CodinGame](https://www.codingame.com/), covering regular programming puzzles, optimization problems, code golf, multiplayer bots, and AI challenges.

My CodinGame profile: [Yasseruvski](https://www.codingame.com/profile/0d647d25cf7b35872d8e9f607f6af1ef330961).

The goal varies with each game: solve a problem correctly, improve an optimization score, write the shortest possible program, or build a bot that competes against other players. Solutions use different languages and approaches depending on the challenge.

Each game has its own directory. Alongside source code, some directories include alternative solutions, strategy notes, test results, and submission records that document how an approach evolved. Individual READMEs provide details where available.

This repository is a record of learning and iteration. Some solutions are polished; others are experiments or work in progress. Historical results may change as CodinGame updates its runtimes, rules, or validators.
